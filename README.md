# CodeAlpha_Calculator

Basic Calculator
A simple, user-friendly calculator built using HTML, CSS, and JavaScript. This project demonstrates fundamental web development skills, providing a functional arithmetic tool right in your browser.

Features :

All Basic Arithmetic Operations: Supports addition (+), subtraction (−), multiplication (×), and division (÷).

Intuitive User Interface: Clean and responsive design with clearly labeled buttons and a large display screen.

Real-time Results: Displays calculation results instantly as you type.

Clear Functionality: A "C" button to clear the current input and reset the calculator.

Decimal Support: Perform calculations with floating-point numbers.

Error Handling: Basic handling for division by zero.


Technologies Used : 

HTML5: For the basic structure and content of the calculator.

CSS3: For styling the calculator's layout, buttons, and overall appearance.

JavaScript : For implementing the calculator's core logic, handling user interactions, and performing calculations.
